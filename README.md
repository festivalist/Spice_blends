# Gewürzmischungen

„Teile“ bezeichnet Mischungsverhältnisse: Verwende für alle Zutaten einer Mischung dieselbe Maßeinheit. EL = Esslöffel, TL = Teelöffel.

**Südwest-Gewürzmischung** (Southwest Spice)

- 2 Teile Knoblauchpulver (garlic powder)
- 1 Teil Kreuzkümmel (cumin)
- 1 Teil Chilipulver (chili powder)

## Hinweise zur Vorlage

- Die Sammlung stammt von einer Privatperson und ist keine offizielle HelloFresh-Rezeptliste.
- Die englischen Überschriften „Sweet Smoky BBQ Spice Blend“ und „Smoky Cinnamon Paprika Spice“ sind in der PDF abgeschnitten und wurden sinngemäß vervollständigt.
- „Chili powder“ wurde als „Chilipulver“ übersetzt. Die Vorlage erläutert nicht, ob damit reines gemahlenes Chili oder eine amerikanische Chili-Gewürzmischung gemeint ist.
- „Dried coriander“ wurde wörtlich als „getrockneter Koriander“ übersetzt. Die Vorlage unterscheidet hier nicht eindeutig zwischen Korianderkraut und Koriandersamen.
- Die beiden Schawarma-Mischungen haben dieselben Zutaten und Mengenverhältnisse.
- Die thailändische Sieben-Gewürze-Mischung enthält laut Vorlage acht Zutaten, darunter Garnelenextraktpulver.
